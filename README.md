# 🚀 Prácticas y Proyectos de Programación

¡Hola! Este repositorio es mi bitácora personal de desarrollo. Aquí alojo todos los códigos elaborados en clases, ejercicios de práctica en casa y pequeñas aplicaciones web y de escritorio que voy construyendo a medida que avanzo en mis estudios de programación.

## 💻 Tecnologías y Lenguajes

En este repositorio encontrarás código desarrollado principalmente en:

*   **Java:** Algoritmos, estructuras de datos y aplicaciones orientadas a objetos.
*   **Desarrollo Web (HTML, CSS, JavaScript):** Maquetación de páginas web, interfaces interactivas y proyectos full-stack.
*   **Otros:** Scripts y configuraciones adicionales utilizadas para mis entornos de desarrollo, si me hes posible phyton y mas lenguajes de programacion.

## 📂 Estructura del Repositorio

El repositorio está organizado por categorías para facilitar la navegación:

*   📁 `/java-practicas` - Ejercicios de lógica de programación y proyectos en Java, algunas que hago por clase/practiccar.
*   📁 `/web-html-css` - Diseños de páginas web, prácticas de maquetación y estilos.
*   📁 `/aplicaciones` - Proyectos más completos o aplicaciones de escritorio/web, esto ya varia entre clase y inspiraciones propias.
*   📁 `/clases` - Apuntes en código y tareas específicas divididas por semestre o materia.

## ⚙️ Cómo ejecutar los proyectos

Dependiendo del tipo de proyecto, las instrucciones varían:

*   **Proyectos en Java:** Se recomienda abrir la carpeta del proyecto en tu IDE de preferencia (como IntelliJ IDEA o Visual Studio Code). Asegúrate de tener configurado el JDK correspondiente (ej. JDK 21) para compilar y ejecutar los archivos `.java`.
*   **Páginas Web (HTML/CSS/JS):** Simplemente navega a la carpeta del proyecto web y abre el archivo `index.html` en cualquier navegador web moderno, o utiliza una extensión como *Live Server* en Visual Studio Code.
*   **Generalmente el profesor de nosotros nos recomienda utilizar mucho IntelliJ IDEA cuando se trata de java, y por parte mia para html entre otros utilizando Visual Studio Code.**
